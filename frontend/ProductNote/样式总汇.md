## 3. 主题机制（src/stores/theme.js）

```js
import { theme, accent, toggleTheme, cycleAccent, setAccent, ACCENTS, ACCENT_LABELS } from '@/stores/theme.js'
```

- `theme`：`'light' | 'dark'`，默认跟随 `prefers-color-scheme`，持久化到 `localStorage('clothing_theme')`
- `accent`：5 套强调色，持久化 `localStorage('clothing_accent')`，`teal` 时不写 `data-accent`
- 应用方式：`document.documentElement` 上设置 `data-theme` / `data-accent`，`main.js` 顶层 import 即生效
- 切换入口：**「系统设置」页面**（`/manage/setting`，`src/page/manage/setting/SystemSetting.vue`）——外观模式（浅色/深色，带界面预览）与主题色（5 色点选）全部集中在此；侧栏只保留入口
- 常用 API：`theme / accent`（响应式值）、`setTheme('light'|'dark')`、`setAccent('teal'|...)`、`toggleTheme()`、`cycleAccent()`

## 4. 重构统计

- 全局样式：958 行（双套覆盖）→ 约 700 行单一体系（含深色/强调色/响应式）
- scoped 样式总量：11,350 行 → 约 9,500 行（删去 330+ 条重复规则）
- 页头三件套：36 文件 173 条 → 全局 1 份
- 弹窗 `.modal-*`：4 个 checkout 组件重复定义 → 全局 1 份
- sku 商品行家族：4 文件 71 条共享规则 → 全局 1 份（文件间相似度从 43-81% 降为仅保留业务差异：列宽、字段名）
- 硬编码色：约 260 处高频色字面量 → Token（剩余多为一次性语义色，见第 6 节）
- 深色模式：全站 Token 驱动自动翻转；`Manage.vue` 侧栏/标签栏/移动端头、Login、POS 家族已显式适配

## 5. 使用规范（给后续开发）

1. **颜色一律用 Token**，禁止新写十六进制近似色；近似色用 `color-mix(in srgb, var(--xxx) NN%, transparent)` 派生
2. **圆角按语义分层**：控件 6-8px / 输入框按钮 10px / 卡片 16px / 弹窗 20px / 胶囊 999px
3. **阴影只用三档变量**，按钮用 `--shadow-primary`
4. **数字/编码用 `--mono` + `tabular-nums`**
5. 新页面优先复用全局类（第 2 节），不要复制页面骨架样式
6. 尊重 CLAUDE.md：flex 布局、不用 grid、不用 `flex:1`、每属性单独一行
7. 深色模式改动验收：`document.documentElement.setAttribute('data-theme','dark')` 后过一遍页面
